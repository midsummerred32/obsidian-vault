## 📥 Backlog (no scheduled date)
```tasks
status.type is TODO
no scheduled date
sort by due
```

## 📅 Scheduled (upcoming)
```tasks
status.type is TODO
scheduled after today
sort by scheduled
```

## 🎯 Today / Overdue
```tasks
status.type is TODO
scheduled before tomorrow
sort by scheduled
```

## 🔧 In Progress
```tasks
status.type is IN_PROGRESS
sort by due
```

## ✅ Done (last 7 days)
```tasks
done after 7 days ago
sort by done reverse
```
